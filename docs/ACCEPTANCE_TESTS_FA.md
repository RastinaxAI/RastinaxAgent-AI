## Automated — بدون کلید واقعی

- [x] ساخت پیام سیستم سمت سرور و رد roleهای system/developer/tool ورودی
- [x] مدل و Provider از Environment؛ ممنوعیت OpenRouter/Kilo پولی به‌صورت پیش‌فرض
- [x] استریم تک‌درخواست معمولی، اجرای ابزار و نوبت پاسخ پس از tool call
- [x] Fallback روی 429 قبل از انتشار متن و ممنوعیت Fallback پس از انتشار
- [x] رد آرگومان نامعتبر ابزار و حذف آمار ساختگی
